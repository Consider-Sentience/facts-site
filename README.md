# facts-site

A single-page site for FACTS, a framework for including non-human animals in how AI systems are designed (Fairness, Accountability, Consideration, Transparency, Scope). It walks from the problem, through proxy stakeholder profiles and a welfare impact map, to the framework, a test of three AI models, and the FACTScan tool.

Built with Vite and React. Colors, spacing, and type come from the shared [cs-design-system](https://github.com/Consider-Sentience/cs-design-system) tokens.

```
npm install
npm run dev
npm run build
```
